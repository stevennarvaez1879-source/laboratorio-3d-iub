# Matrix 3D Lab — IUB

Proyecto académico: **Creación de figuras geométricas 3D utilizando Python**.

## Tecnologías
- Python
- Streamlit
- NumPy
- Plotly
- Pandas

## Figuras
Cubo, Esfera, Cilindro, Cono, Pirámide y Prisma triangular.

## Funciones principales
- Modo 3D interactivo con rotación y zoom.
- Modo 2D con plano XY y corte XZ.
- Ecuaciones / definiciones matemáticas para cada figura.
- Fórmulas de área y volumen con cálculo en tiempo real.
- Código Python representativo visible dentro de la app.
- Vistas isométrica, frontal, lateral y superior.
- Modo exposición.
- Diseño oscuro premium inspirado en interfaces digitales tipo Matrix.

## Ejecutar en Windows
1. Instala Python 3.11 o superior.
2. Abre una terminal en esta carpeta.
3. Ejecuta:

```bash
pip install -r requirements.txt
streamlit run app.py
```

O usa `INICIAR_APP.bat`.

## Publicar
La opción recomendada es **Streamlit Community Cloud**:
1. Sube esta carpeta a un repositorio de GitHub.
2. En Streamlit Community Cloud crea una app nueva.
3. Selecciona el repositorio y `app.py` como archivo principal.
4. Obtendrás un enlace web público para mostrar al profesor.
